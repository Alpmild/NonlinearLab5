Задание на лабораторную работу №5:
1. Реализовать метод синхронизации Пекоры-Кэррола, выполнить синхронизацию по каждой переменной в отдельности (если это возможно).
2. Реализовать метод двунаправленной синхронизации, выполнить синхронизацию по каждой переменной в отдельности (если это возможно).
3. Реализовать метод возвратной синхронизации, выполнить синхронизацию по каждой переменной в отдельности (если это возможно).
4. Вывести траектории по времени ведущей и ведомой системы, графики ошибки синхронизации. Для возвратной синхронизации график ошибки по итерациям.
